# 🎓 PS VISION ACADEMY

A responsive tuition management website developed for **PS Vision Academy** to provide students of **Classes 8th–12th** with online admission, study materials, and institute information.

## 🚀 Features

- 📚 Class-wise & Subject-wise Notes
- 🔒 Student Registration & Login
- 📱 Fully Responsive Design
- 💬 WhatsApp Chat Integration
- 📩 EmailJS Contact & Admission Form
- 📍 Google Maps Integration
- 🖥️ Smart Class & Online Learning Information
- 🎯 Clean and User-Friendly Interface

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase Authentication
- Firebase Firestore
- EmailJS
- Google Maps Embed API
